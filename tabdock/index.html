TabDock BETA

Browser-style tabs for any Mac window. Group windows from different apps under one tab bar, switch with a click or a shortcut, and drag windows in and out.

Getting started

  1. Open the downloaded file and drag TabDock to Applications, then open it. TabDock lives in the menu bar and has no Dock icon.
  2. Allow TabDock under System Settings → Privacy & Security → Accessibility. TabDock asks for this on first launch; it needs it to move and switch the windows of other apps.
  3. Click the TabDock icon in the menu bar, choose New Group … and pick a window. The tab bar appears on top of it.
  4. Add windows with the + in the tab bar, or drag any window by its title bar onto the bar.

Everyday use

  • Click a tab to switch. ⌃⌘1–⌃⌘9 jump to a tab, ⌃⌘← / ⌃⌘→ go to the previous or next tab (Settings lets you change the prefix).
  • Drag a tab to reorder it, or out of the bar to remove it. The × on a tab removes and minimizes its window.
  • ⌃⌘T brings back the last removed tab.
  • Drag empty space in the bar to move the whole group. Ungroup or Quit puts every window back where it was.

About the beta

TabDock is free while it is in beta. Each beta expires 60 days after it was built: it keeps working, but asks you to download the current version so your reports match the latest fixes. TabDock checks this page twice a day for a newer beta and tells you when one is available.

Every app handles its windows a little differently, so the most useful reports name the apps you grouped and what happened.

Data & privacy

TabDock never reads screen contents and does not need screen recording permission. Window positions and your last group stay on your Mac; window titles are stored only as hashes. TabDock has no account, analytics or ads.

The only network request is the beta update check, which downloads beta.json from this site. Problem reports are emails you send yourself; you can read the attached diagnostics before sending. They contain app and macOS versions, the names of the grouped apps and recent error messages, never window titles or contents.

Help & troubleshooting

Report a problem

  • Choose Report a Problem … in the TabDock menu bar menu or the group menu at the right end of the tab bar. It opens an email to us with the diagnostics filled in; add what happened and, if you can, a screenshot or short screen recording.

Arrow-key shortcuts don’t switch tabs

  • Another app already uses the same keys. TabDock uses ⌃⌘ by default because window managers such as Rectangle and Magnet take ⌃⌥ with the arrow keys. Pick a different prefix in TabDock → Settings. Settings warns you if you pick ⌃⌥ while Rectangle or Magnet is running.

A window doesn’t appear in the list

  • Full-screen windows, dialogs and windows on other Spaces can’t be grouped. Leave full screen or move the window to the current Space, then try again.

TabDock says it needs Accessibility access again

  • This can happen after replacing the app with a newer beta. Turn TabDock off and on again under System Settings → Privacy & Security → Accessibility.
